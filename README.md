# Codec Technologies AI Internship Projects

This repository contains the final project submissions for the 1-Month Artificial Intelligence Internship at Codec Technologies.

## Projects Included

### 1. Customer Service Chatbot
A rule-based Natural Language Processing (NLP) chatbot designed to handle standard customer support queries.
* **Features:** Keyword pattern matching and automated responses for business hours, order tracking, and return policies.
* **Tech Stack:** Python, `re` (Regular Expressions)
* **File:** `chatbot.py`

### 2. Spam Email Classifier
A machine learning classification model that categorizes emails as either "Spam" or "Ham" (Not Spam) based on their text content.
* **Features:** Text vectorization using `CountVectorizer`, trained via the `MultinomialNB` (Naive Bayes) classification algorithm.
* **Tech Stack:** Python, Scikit-Learn
* **File:** `spam_classifier.py`

## How to Run

1. Clone the repository:
   git clone [https://github.com/your-username/Codec-AI-Internship.git](https://github.com/your-username/Codec-AI-Internship.git)
   cd Codec-AI-Internship

2. Install the required dependencies:
    pip install scikit-learn

3. Execute the scripts:
    python chatbot.py
    python spam_classifier.py
